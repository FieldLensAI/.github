# FieldLensAI

FieldLens is a planning-to-execution reconciliation layer for infrastructure projects.

It converts field evidence such as DPRs, spreadsheets, site diaries, and supervisor updates into structured, schedule-linked actuals for L5/L6 activities.

```text
Field Evidence
      ↓
Event Extraction
      ↓
L5/L6 Reconciliation
      ↓
Evidence Validation
      ↓
Verified Actuals
      ↓
Project Schedule
```

## Repositories

* **fieldlens** — Core application
* **fieldlens-docs** — Documentation and architecture
* **fieldlens-data** — Synthetic datasets and evaluation data
* **fieldlens-cv** — Computer vision components
* **fieldlens-integrations** — PMIS and schedule integrations
